# KoshPack Updates

Public update feed for KoshPack.

This repository contains only files that are safe to distribute publicly. The live updater manifest is `manifest.json`.

Current state: **test_event OFF**.

NeoForge compatibility: **21.1.x**. Manifests use `"neoforge": "21.1"` intentionally; KoshPackUpdater alpha6 accepts any NeoForge version in the 21.1 line, so Prism on 21.1.249 and TLauncher on 21.1.250 are both valid targets.

The test event JAR is a tiny KoshPack-owned NeoForge low-code marker used only to verify automatic install/remove behavior before any real event mods are enabled.
